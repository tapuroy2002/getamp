04FAQ

Questions.

Is Amp really free?
Yes. No price, no ads, no account, and nothing locked behind a subscription.
Why does Windows warn me when I install it?
The installer isn't code-signed yet, so Windows SmartScreen doesn't recognise it. Click More info, then Run anyway. You only see this once.
How do updates work?
A few seconds after Amp starts, it checks for a new version. If there is one, it asks you. Click Update now and it downloads, installs and opens again by itself. Your library and settings stay.
Does it change how my music sounds?
Only if you ask it to. With the equalizer off and exclusive mode on, Amp sends your files to the sound card exactly as they are. Nothing turns on by itself.
How do I install it on Android?
Tap Download for Android and open the file when it finishes. Android asks once to allow installs from your browser: tap Settings, turn on Allow from this source, go back and tap Install. Pick Latest phones or Older phones; if you're not sure, tap Check my phone and Amp picks the right one for you.
How do I update on Android?
Download the newest version from this page and install it over the one you have. Your songs, playlists and settings stay.
Can I use it without installing?
Yes. Download the portable zip from the bottom of this page, unzip it anywhere and run Amp.exe. The portable copy doesn't update itself, so download new versions by hand.
